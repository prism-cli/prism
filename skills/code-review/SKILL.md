# Code Review Skill

Use this skill when reviewing code changes, pull requests, or refactoring plans.

## Steps
1. **Analyze Diff**: Inspect modified files for unexpected changes or regressions.
2. **Security Audit**: Check for unsafe input handling, credential exposure, and SQL/Command injection.
3. **Clean Code**: Ensure single responsibility principle and self-documenting code.
4. **Actionable Suggestions**: Provide concise diffs explaining the rationale for any suggested improvements.
