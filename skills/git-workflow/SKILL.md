# Git Workflow Skill

Use this skill when staging, committing, or preparing pull requests.

## Guidelines
1. **Conventional Commits**: Use format `<type>(<scope>): <short description>` (e.g. `feat:`, `fix:`, `refactor:`).
2. **Atomic Commits**: Keep commits small, focused, and independently testable.
3. **Clean Branching**: Maintain clean branch history rebased against main.
